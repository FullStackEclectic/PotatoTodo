### 3. 使用指南

#### 离线支持
土豆Todo提供完整的离线支持功能，允许用户在没有网络连接的情况下使用应用的所有核心功能：

1. **自动检测网络状态**：应用会自动检测网络连接状态，并在界面顶部显示当前是否处于离线模式。
2. **离线数据创建**：在离线状态下，您仍然可以创建新任务、编辑现有任务和管理所有数据。
3. **自动数据同步**：一旦网络连接恢复，应用会提示您同步离线创建的数据。
4. **数据冲突处理**：应用会智能处理数据冲突，确保您的数据不会丢失。

#### 数据备份与恢复
保护您的数据安全是我们的首要任务，土豆Todo提供了简单而强大的数据备份和恢复功能：

1. **数据导出**：
   - 在设置页面中，点击"导出数据"
   - 选择保存位置
   - 所有任务、类别、习惯等数据将被导出为JSON文件

2. **数据导入**：
   - 在设置页面中，点击"导入数据"
   - 选择之前导出的JSON文件
   - 确认导入后，所有数据将被恢复

3. **注意事项**：
   - 导入操作将覆盖当前所有数据，请谨慎操作
   - 建议定期导出数据，确保重要信息不会丢失
   - 导入后可能需要重启应用以完成数据同步
